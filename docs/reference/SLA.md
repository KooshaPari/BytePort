# BytePort Service Level Agreement (SLA)

## Service Commitments

| Metric | Target | Measurement | Reporting |
|--------|--------|-------------|-----------|
| **Availability** | 99.9% uptime (monthly) | `/healthz` endpoint success rate | Grafana `byteport-overview` |
| **API Latency (p95)** | < 500ms | Request duration histogram | `/metrics` (prometheus) |
| **API Latency (p99)** | < 2000ms | Request duration histogram | `/metrics` (prometheus) |
| **Deployment time** | < 60s (p90) | End-to-end deployment duration | Custom metric |
| **Error rate** | < 0.1% of requests | HTTP 5xx / total requests | Grafana `byteport-errors` |

## Availability Calculation

```
Monthly Uptime % = (Total Minutes − Downtime Minutes) / Total Minutes × 100
```

**Exclusions:**
- Planned maintenance (notified ≥ 7 days in advance via status page)
- Customer-caused outages (misconfiguration, exhausted quota)
- Force majeure events outside BytePort's reasonable control

## Service Credits

| Monthly Uptime | Credit (% of monthly fee) |
|----------------|---------------------------|
| < 99.9% | 5% |
| < 99.0% | 10% |
| < 95.0% | 25% |

Credits are applied as account balance within 30 days of claim submission.

## Monitoring & Reporting

All SLIs are collected via:
- **Prometheus** metrics (exposed at `/metrics`)
- **Grafana** dashboards (`observability/grafana/dashboards/`)
- **Circuit breakers** (`backend/internal/infrastructure/resilience/`)
- **Health endpoints** (`/healthz`, `/readyz`)

Monthly SLA reports are generated by the `pillar-audit.yml` workflow.
